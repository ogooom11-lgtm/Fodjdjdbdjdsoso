# تطبيق امتحان الدروس الهجائية 📖

تطبيق أندرويد بالفلاتر لامتحان أسئلة كتاب الدروس الهجائية: 76 سؤالاً
(52 سؤالاً من ملخصات ومخططات الكتاب + 24 سؤالاً من ورقة أسئلة المعلمة)،
وكل سؤال يحمل **الإجابة الصحيحة + الشرح + المرجع من الكتاب (رقم الصفحة المطبوعة ورقم صفحة PDF)**.

## المزايا المطلوبة والمنفذة
- أسئلة **عشوائية بدون تكرار** داخل الامتحان الواحد، ويمكن عمل امتحانات غير محدودة.
- **اختيار عدد الأسئلة**: 5 / 10 / 15 / 20 / 25 / **كل الأسئلة**.
- **اختيار مصدر الأسئلة**: الكل / ملخصات الكتاب / أسئلة المعلمة / بنك الأخطاء.
- **نظام علامة**: عدّاد مباشر أثناء الامتحان + شاشة نتيجة بنسبة مئوية متحركة.
- **بنك الأسئلة الخطأ**: كل خطأ يُحفظ تلقائياً (ويبقى بعد إغلاق التطبيق) مع
  الإجابة الصحيحة والشرح و«الدليل من الكتاب»، مع زر «امتحان جديد من أخطائك».
- تصميم عصري فخم (ليلي/ذهبي/زمردي) عربي RTL مع أنيميشن وتفاعلات، وأيقونة تطبيق مخصصة.

## التشغيل
1) ثبّت Flutter من الموقع الرسمي.
2) داخل مجلد `exam_app`:
```bash
flutter create . --platforms=android     # ينشئ مجلد android وgradle wrapper
bash setup_android.sh                    # ينسخ الأيقونة ويضبط اسم التطبيق
flutter run                              # أو: flutter build apk
```
> ملاحظة: `flutter create .` لا يمس ملفات `lib/` أو `assets/` الموجودة، بل يكمل نواقص المنصات فقط.

## الملفات المهمة
- `assets/questions.json` — بنك الأسئلة الكامل مع المراجع (يُقرأ عند بدء التطبيق).
- `lib/services/engine.dart` — الاختيار العشوائي بلا تكرار.
- `lib/services/store.dart` — حفظ بنك الأخطاء على الجهاز.
- `lib/screens/` — الرئيسية / الامتحان / النتيجة / مراجعة الأخطاء.
- `assets/icon/ic_launcher.png` — أيقونة التطبيق.

## توثيق الصفحات
أرقام الصفحات في التطبيق وفي ملفي الإجابات بصيغة «المطبوعة X / PDF Y»
(النسخة المصوّرة تبدأ بالمطبوعة 5 أي Y = X + 4). الصفحات المرجعية قُرئت من
النسخة المصوّرة مباشرة للتحقق. صفحات المقدمة/الفوائد (المطبوعات 1–4 تقريباً)
غير موجودة في نسخة الـPDF المرفقة، والأسئلة التي مصدرها هناك موثقة في التطبيق
بعبارة «غير موجود بالنسخة المرفقة» مع أقرب شاهد.
